Q2. Explain Bisection Method for finding root of f(x) = 0. State its merits and demerits.
4 Marks2017, 2021, 2023▼

📘 Introduction

Bisection method (also called Bolzano's method) is a root-finding method that repeatedly halves an interval until the root is isolated, based on the Intermediate Value Theorem.

📐 Algorithm

  • Step 1: Find [a,b] such that f(a)·f(b) < 0 (sign change)
  • Step 2: Compute midpoint: x₁ = (a+b)/2
  • Step 3: If f(x₁) = 0 → root found. Stop.
  • Step 4: If f(a)·f(x₁) < 0 → root in [a, x₁], set b = x₁
  • Step 5: Else → root in [x₁, b], set a = x₁
  • Step 6: Repeat until |b−a| < ε (required accuracy)
Number of iterations needed: n ≥ log₂[(b−a)/ε]

✅ Merits & Demerits

Merits: Always convergent · Simple and reliable · No derivative needed

Demerits: Slow (linear convergence) · Requires sign change · Gives only one root at a time

📌 Conclusion

Bisection is reliable but slow. For speed, Newton-Raphson (quadratic convergence) is preferred when f'(x) is known.

Q4. Describe the Method of False Position (Regula Falsi). How does it differ from Bisection?
4 Marks2016, 2023▼

📘 Introduction

Regula Falsi (False Position) is an improved bracket method. Instead of bisecting, it uses linear interpolation (a straight line through the two endpoint values) to locate the next approximation.

📐 Formula

x₁ = [a·f(b) − b·f(a)] / [f(b) − f(a)]
  • If f(a)·f(x₁) < 0 → root in [a, x₁], set b = x₁
  • Else → root in [x₁, b], set a = x₁
  • Repeat until convergence

🔢 Bisection vs Regula Falsi

FeatureBisectionRegula Falsi
Next pointMidpoint (a+b)/2Linear interpolation
SpeedSlowerFaster (generally)
ConvergenceLinear (always)Linear (may be slow)

📌 Conclusion

Regula Falsi converges faster than bisection but can be slow if one endpoint barely changes. It always converges and needs same sign-change condition.

Q2. Derive Newton-Raphson formula. Find √12 correct to five decimal places using N-R method.
12 Marks2014, 2025▼

📘 Derivation of Newton-Raphson Formula

Let xₙ be an approximate root of f(x) = 0. Expand f(x) in Taylor's series about xₙ:

f(x) = f(xₙ) + (x−xₙ)f'(xₙ) + (x−xₙ)²/2! f''(xₙ) + …

📐 Derivation Steps

1
Neglect 2nd and higher order terms: f(x) ≈ f(xₙ) + (x−xₙ)f'(xₙ)
2
Set f(x) = 0 to find next approximation xₙ₊₁: 0 = f(xₙ) + (xₙ₊₁−xₙ)f'(xₙ)
3
Solve for xₙ₊₁:
xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ) ← NEWTON-RAPHSON FORMULA

Convergence: Quadratic (error squares each iteration) — very fast!

🔢 Application: Find √12

N-R formula: xₙ₊₁ = xₙ − (xₙ²−12)/(2xₙ) = (xₙ + 12/xₙ)/2

Start: x₀ = 3 (since 3² = 9 close to 12)

Q1. Define operators Δ and ∇. Prove that Δ(y²ₖ) = (yₖ + yₖ₊₁)·Δyₖ
4 Marks2014▼

📘 Definitions

Forward Difference (Δ): Δf(x) = f(x+h) − f(x)

Backward Difference (∇): ∇f(x) = f(x) − f(x−h)

Shift Operator (E): Ef(x) = f(x+h); so Δ = E−1, ∇ = 1−E⁻¹

📐 Proof: Δ(y²ₖ) = (yₖ + yₖ₊₁)·Δyₖ

🔢 Solution

LHS: Δ(y²ₖ) = y²ₖ₊₁ − y²ₖ

Using algebraic identity a² − b² = (a+b)(a−b):

= (yₖ₊₁ + yₖ)(yₖ₊₁ − yₖ)

= (yₖ + yₖ₊₁) · Δyₖ     [since Δyₖ = yₖ₊₁ − yₖ]

= RHS ✓

📌 Conclusion

This identity is analogous to the product rule in differential calculus. It shows that Δ behaves like a difference derivative.

Q2. Prove that the third divided difference of f(x) = 1/x with arguments p, q, r, s is −1/(pqrs).
4 Marks2014▼

📐 First Divided Differences

f[p,q] = (f(q)−f(p))/(q−p) = (1/q − 1/p)/(q−p) = (p−q)/(pq(q−p)) = −1/(pq)

Similarly: f[q,r] = −1/(qr) and f[r,s] = −1/(rs)

🔢 Second Divided Differences

f[p,q,r] = (f[q,r]−f[p,q])/(r−p)

= (−1/(qr) − (−1/(pq)))/(r−p)

= (1/(pq) − 1/(qr))/(r−p)

= (r−p)/(pqr(r−p)) = 1/(pqr)

Third Divided Difference

f[p,q,r,s] = (f[q,r,s]−f[p,q,r])/(s−p)

= (1/(qrs) − 1/(pqr))/(s−p)

= (p−s)/(pqrs(s−p))

f[p,q,r,s] = −1/(pqrs) ✓

📌 Conclusion

Third divided difference of 1/x = −1/(pqrs). This shows divided differences of 1/x follow a beautiful pattern: f[x₀,…,xₙ] = (−1)ⁿ/(x₀x₁…xₙ).

Q3. Discuss Divided Differences and state their important properties.

📘 Definition

1st Divided Diff: f[x₀,x₁] = (f(x₁)−f(x₀))/(x₁−x₀)

2nd: f[x₀,x₁,x₂] = (f[x₁,x₂]−f[x₀,x₁])/(x₂−x₀)

nth: f[x₀,…,xₙ] = Σᵢ f(xᵢ)/∏ⱼ≠ᵢ(xᵢ−xⱼ)

📐 Properties (5 Key Properties)

  • 1. Symmetry: f[x₀,x₁,…,xₙ] is symmetric — value unchanged if arguments permuted
  • 2. Linearity: f[x₀,x₁] = Δf(x₀)/h for equal spacing
  • 3. Polynomial: nth divided diff of degree-n polynomial = n! × leading coefficient
  • 4. Zero property: (n+1)th divided diff of degree-n polynomial = 0
  • 5. Mean value: f[x₀,x₁,…,xₙ] = f⁽ⁿ⁾(ξ)/n! for some ξ in range

📌 Application

Used in Newton's divided difference interpolation formula — works for unequally spaced data, unlike Newton's forward/backward formulas.
