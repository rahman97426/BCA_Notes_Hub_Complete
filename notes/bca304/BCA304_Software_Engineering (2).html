🚀 Last Minute Cheat Sheet

Quick revision — formulas, tricks, differences, one-liners

📋 Full Forms

  • SE = Software Engineering
  • SRS = Software Requirements Specification
  • COCOMO = Constructive Cost Model
  • LOC = Lines of Code
  • FP = Function Points
  • DFD = Data Flow Diagram
  • OOD = Object Oriented Design
  • SQA = Software Quality Assurance
  • CMM = Capability Maturity Model
  • V&V = Verification & Validation
  • CI = Continuous Integration
  • SLIM = Software LIfecycle Model

🔢 Key Formulas

COCOMO: E = a × (KLOC)^b Organic: a=2.4, b=1.05 Semi-detached: a=3.0, b=1.12 Embedded: a=3.6, b=1.20 Musa: λ(τ) = f × K × [N − μ(τ)] Halstead: n=n1+n2, N=N1+N2
  • n1=distinct operators
  • n2=distinct operands
  • N1=total operators
  • N2=total operands

🧠 Memory Tricks

  • Waterfall = water flows DOWN (no going back)
  • Spiral = RISK at every loop
  • Coupling worst→best: CC3SD
  • SRS chars: CCCCVM (Correct,Consistent,Complete,Concise,Verifiable,Modifiable)
  • CMM 5 levels: I R D M O
  • Maintenance: CAPP (Corrective,Adaptive,Perfective,Preventive)
  • OOD pillars: APIE (Abstraction,Polymorphism,Inheritance,Encapsulation)
  • DFD: P=round, Flow=arrow, Store=║, Entity=□

⚠️ Common Mistakes

  • Waterfall = NO iteration (rigid)
  • Prototype = NOT the final product
  • White Box = internal code view
  • Black Box = external user view
  • ISO 9000 = quality SYSTEM standard
  • CMM Level 1 = chaotic (bad!)
  • Verification = "Building it right"
  • Validation = "Building the right thing"
  • DFD Level 0 = Context Diagram
  • Error→Fault→Defect→Failure (order!)

📊 Models Comparison

  • Waterfall: Sequential, rigid, clear requirements
  • Prototype: Iterative, unclear requirements
  • Spiral: Risk-driven, 4 quadrants, large projects
  • FOD: Function-based, top-down, DFDs
  • OOD: Object-based, reusable, APIE
  • LOC: Simple, language-dependent
  • FP: Functional, language-independent
  • COCOMO Organic: Small team, simple
  • COCOMO Embedded: Real-time, complex
  • ISO vs CMM: Standard vs 5-level model

⚡ Quick One-Liners

  • SE = systematic, disciplined, quantifiable
  • Software crisis = 1960s project failures
  • Spiral = 4 quadrants: Plan, Risk, Dev, Eval
  • Conceptual=WHAT; Technical=HOW
  • Content coupling = worst; Data = best
  • Statement < Branch < Path coverage
  • Unit test by developer; System test by tester
  • Corrective = fix bugs; Adaptive = new env
  • Perfective = new features; Preventive = future
  • Reverse = code→design→requirements
