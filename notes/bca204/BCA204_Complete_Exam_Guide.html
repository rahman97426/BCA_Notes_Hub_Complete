📘 Definition:
Relational operators compare two values or expressions. They return 1 (true) if condition is met, or 0 (false) if not.
📋 Key Points:
  1. == : Equal to — if(a == b)
  2. != : Not equal to — if(a != b)

Explain all types of operators in C with examples and operator precedence.
12 Marks 2015 ✅ 2016 ✅ 2019 ✅

📘 Introduction:
An operator is a symbol that tells the computer to perform a specific mathematical or logical operation on operands. C has a rich set of operators.
▶ 1. Arithmetic Operators:
+ (Add), - (Sub), * (Mul), / (Div), % (Modulus)
Example: int a=10, b=3; a/b=3; a%b=1
▶ 2. Relational Operators:
== (equal), != (not equal), > (greater), < (less), >= (ge), <= (le)
Return 1(true) or 0(false). Used in conditions.
▶ 3. Logical Operators:
&& (AND) — both true
|| (OR) — either true
! (NOT) — invert
Example: if(a>0 && b>0)
▶ 4. Assignment Operators:
= (assign), += (add-assign), -= (sub-assign), *= (mul-assign), /= (div-assign), %= (mod-assign)
a += 5 means a = a + 5
▶ 5. Unary Operators:
++ (increment), -- (decrement), ! (logical NOT), ~ (bitwise NOT), sizeof()
++a = pre-increment (increment first then use)
a++ = post-increment (use first then increment)
▶ 6. Ternary Operator:
Syntax: condition ? value_if_true : value_if_false
Example: max = (a>b) ? a : b; // short form of if-else
▶ 7. Bitwise Operators:
& (AND), | (OR), ^ (XOR), ~ (NOT), << (left shift), >> (right shift)
Example: 5&3=1(0101&0011=0001), 5<<1=10 (×2)

Evaluates left to right, returns rightmost value.
Example: c = (a=2, b=4, a+b); // c = 6

Q
What is recursion? Explain its advantages and disadvantages.
4 Marks PYQ 2014
▼
📘 Definition:
Recursion is a process where a function calls itself repeatedly to solve a problem. A function that calls itself is called a recursive function. It must have a base condition to stop.
📋 Key Points:
  1. Base Case: Stopping condition (e.g., if n==0 return 1)
  2. Recursive Call: Moves toward base case
  3. Example: fact(4) = 4×fact(3) = 4×3×fact(2) = ... = 24
  4. ✅ Advantages: Code is short, clean; useful for factorial, Fibonacci, trees
  5. ❌ Disadvantages: Slower (call overhead); uses stack memory; stack overflow if base missing
✏️ Conclusion:
Recursion simplifies complex problems but has performance cost. ALWAYS include a base case — without it the program crashes with Stack Overflow.

Q
What do you mean by call by value and call by reference? Write a program to swap two numbers using both methods.
12 Marks 2015 ✅ 2016 ✅ 2019 ✅ 2021 ✅
▼
📘 Introduction:
In C, when a function is called, arguments can be passed in two ways: Call by Value and Call by Reference. Understanding this is fundamental to function programming.
▶ Call by Value:
A COPY of the actual argument is passed to the function.
Changes made inside function DO NOT affect original variables.
This is the default method in C.
▶ Call by Reference:
The ADDRESS of the actual argument is passed to the function.
Changes made inside function DO affect original variables.
Requires * (dereference) and & (address-of) operators.
📊 Comparison Table:
FeatureCall by ValueCall by Reference
What is passedCopy of valueAddress (&)
Original affected?NOYES
OperatorsNone* and &
MemoryMore (copy made)Less
SafetySafeRisky if misused
Use caseRead-only operationsModify original values
💻 Program:
#include <stdio.h>

/* Call by Value — DOES NOT swap original */
void swap_val(int a, int b) {
    int t = a; a = b; b = t;
}  /* Changes lost when function returns */

/* Call by Reference — DOES swap original */
void swap_ref(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 5, y = 10;
    swap_val(x, y);
    printf("By Value: x=%d y=%d\n", x, y);  /* 5 10 */
    swap_ref(&x, &y);
    printf("By Ref:   x=%d y=%d\n", x, y);  /* 10 5 */
    return 0;
}
/* Output:
   By Value: x=5 y=10
   By Ref:   x=10 y=5 */
✏️ Conclusion:
Call by value is safe but cannot modify originals. Call by reference uses pointers and can modify originals. Always use & when passing and * when accessing in function. Swap using call by value FAILS; swap using call by reference SUCCEEDS.
Q
What are advantages and disadvantages of recursive function? Write a program to print Fibonacci series using recursion. Also write program for factorial.
12 Marks 2015 ✅ 2016 ✅ 2017 ✅
▼
📘 Introduction:
Recursion is a powerful programming technique where a function calls itself. It is particularly useful for problems that have a naturally recursive structure.
▶ Advantages:
1. Code is shorter and more readable
2. Natural for factorial, Fibonacci, tree traversal
3. Reduces complexity of some algorithms
▶ Disadvantages:
1. Slower — function call overhead each time
2. More memory — each call uses stack space
3. Stack Overflow if base case is missing
4. Harder to debug than iteration
▶ Recursion Stack (factorial 4):
fact(4) = 4 × fact(3)
  fact(3) = 3 × fact(2)
    fact(2) = 2 × fact(1)
      fact(1) = 1  ← BASE CASE
← Unwind: 2 → 6 → 24
💻 Program:
#include <stdio.h>

/* Factorial */
long long factorial(int n) {
    if(n==0 || n==1) return 1;        /* Base case */
    return n * factorial(n-1);         /* Recursive call */
}

/* Fibonacci */
int fib(int n) {
    if(n<=1) return n;                 /* Base: fib(0)=0, fib(1)=1 */
    return fib(n-1) + fib(n-2);
}

int main() {
    int n;
    printf("Enter n: "); scanf("%d", &n);
    printf("Factorial of %d = %lld\n", n, factorial(n));
    printf("Fibonacci: ");
    for(int i=0; i<n; i++) printf("%d ", fib(i));
    return 0;
}
/* n=5: Factorial=120, Fibonacci: 0 1 1 2 3 */
✏️ Conclusion:
Recursion requires two things: (1) Base case to stop, (2) Recursive call moving toward base. factorial(n) = n×fact(n-1); base=1. fib(n)=fib(n-1)+fib(n-2); base: fib(0)=0, fib(1)=1. For performance-critical code, use iteration instead of recursion.

What is an array? Explain 1D and 2D arrays with memory layout, initialization, and programs. Also explain passing arrays to functions.
12 Marks 2014 ✅ 2015 ✅ 2016 ✅ 2019 ✅
▼
📘 Introduction:
An array is a collection of similar data elements stored in contiguous memory locations under a single name, accessed using an index. It is the most fundamental data structure in C.
▶ 1D Array:
Declaration: int marks[5];
Initialization: int marks[5] = {10,20,30,40,50};
Access: marks[0]=10, marks[4]=50
Index starts from 0; last valid index = size-1
▶ 1D Memory Layout:
marks[5] = {10,20,30,40,50}
Index:  0    1    2    3    4
Value: 10   20   30   40   50
Addr: 1000 1004 1008 1012 1016  (int=4 bytes)
▶ 2D Array:
Declaration: int m[2][3];
Init: int m[2][3]={{1,2,3},{4,5,6}};
     Col:  0   1   2
Row 0:    [1] [2] [3]
Row 1:    [4] [5] [6]
Address = Base + (i*cols+j)*sizeof
▶ Advantages:
✅ Multiple values under one name
✅ Random access in O(1)
✅ Easy loop traversal
❌ Fixed size — cannot expand
❌ Only same data type
💻 Program:
#include <stdio.h>

/* Passing array to function */
void printArr(int a[], int n) {
    for(int i=0; i<n; i++)
        printf("%d ", a[i]);
}

/* Find smallest in array */
int smallest(int a[], int n) {
    int min = a[0];
    for(int i=1; i<n; i++)
        if(a[i] < min) min = a[i];
    return min;
}

int main() {
    int a[5] = {30,10,50,20,40};
    printArr(a, 5);            /* 30 10 50 20 40 */
    printf("\nSmallest=%d", smallest(a,5));  /* 10 */
    return 0;
}
✏️ Conclusion:
Arrays are passed to functions by reference (address). The array name itself is a pointer to the first element. a[i] = *(a+i). For 2D arrays, pass both row and column count. Arrays cannot return from functions directly — use pointers.
Q
Give the advantage of array using pointers. Write a program to access elements of an array by using pointers. Also write program to find length of string using pointer.
12 Marks 2015 ✅ 2016 ✅
▼
📘 Introduction:
Arrays and pointers are closely related in C. The array name itself is a constant pointer to its first element. This relationship allows powerful manipulation using pointer arithmetic.
▶ Array-Pointer Relationship:
a[i]  ≡  *(a + i)    // equivalent expressions
&a[i] ≡  a + i       // equivalent addresses
a     ≡  &a[0]       // array name = base address

Pointer arithmetic: ptr+1 moves by sizeof(datatype)
For int*: moves 4 bytes
For char*: moves 1 byte
▶ Advantages of Using Pointers with Arrays:
1. Faster traversal (pointer increment vs index calc)
2. Efficient passing to functions (single address)
3. Dynamic arrays possible (malloc)
4. Can traverse strings easily (until \0)
5. Pointer arithmetic is more efficient
💻 Program:
#include <stdio.h>

/* Access array elements using pointers */
void accessArr() {
    int a[5]={10,20,30,40,50};
    int *p = a;  /* p = &a[0] */
    printf("Array using pointer:\n");
    for(int i=0; i<5; i++)
        printf("a[%d]=%d\n", i, *(p+i));
}

/* String length using pointer */
int strLen(char *s) {
    int len = 0;
    while(*s != '\0') { len++; s++; }
    return len;
}

int main() {
    accessArr();
    char str[50];
    printf("Enter string: ");
    scanf("%s", str);
    printf("Length = %d", strLen(str));
    return 0;
}
/* Output:
   a[0]=10, a[1]=20 ... a[4]=50
   Enter string: Hello → Length = 5 */
✏️ Conclusion:
Arrays and pointers are two faces of the same coin in C. a[i] = *(a+i) is fundamental. Pointer traversal is faster. String length using pointer: walk until \0 and count steps. Array name is a constant pointer; we cannot do a++ but can do p++ where p=a.

Q
What is structure? What is union? Explain their differences. Write programs using both. Also explain self-referential structure.
12 Marks 2015 ✅ 2016 ✅ 2017 ✅ 2018 ✅ 2022 ✅
▼
📘 Introduction:
C provides user-defined data types — structure and union — that allow storing different types of data together. Understanding both and their differences is very important for the exam.
▶ 1. Structure:
Collection of variables of different data types under one name.
Each member has SEPARATE memory.
Size = Sum of all members + padding.
Access: variable.member or pointer->member
▶ 2. Union:
Similar to structure but all members SHARE same memory.
Only ONE member can hold value at a time.
Size = size of LARGEST member.
Last written member's value is current.
▶ 3. Self-Referential Structure:
A structure containing a pointer to its own type.
Used for: Linked Lists, Trees, Graphs.
struct Node { int data; struct Node *next; };
Memory: [data|next→] → [data|next→] → NULL

#include <string.h>

    int roll;
    char name[20];

    int i;
    float f;
    char c;
};

/* Self-referential structure */
struct Node {
    int data;
    struct Node *next;
};

void display(struct Student *s) {    /* Pass by reference */
    printf("Roll:%d Name:%s Marks:%.1f\n",
           s->roll, s->name, s->marks);
}

    struct Student s = {101, "Zoha", 85.5};
    display(&s);

    union Data d;
    d.i = 10; printf("d.i=%d\n", d.i);
    d.f = 3.14; printf("d.f=%.2f\n", d.f);
    printf("d.i after f=%d (GARBAGE!)\n", d.i);

Structure stores all members with separate memory — use for complete records. Union saves memory by sharing — use when one field needed at a time. Self-referential structures form the basis of linked lists and trees. Always use → with pointers and . with variables.

"r"  = Read only (file must exist)
"w"  = Write (creates/ERASES existing)
"a"  = Append (adds at end, safe)
"r+" = Read+Write (must exist)
"w+" = Read+Write (creates/erases)
"a+" = Read+Append

fscanf(fp,fmt,...) = read formatted
fputc(ch,fp)       = write one char
fgetc(fp)          = read one char (→EOF)
