Q1: What are identifiers and keywords in C? 4–5 marks

Identifier: An identifier is a name given to variables, functions, arrays, or any user-defined elements in a program.

Rules for Identifiers:

  1. Must start with a letter (A-Z or a-z) or underscore (_)
  2. Can contain letters, digits (0-9), and underscore only
  3. Cannot start with a digit (e.g., 1sum is INVALID)
  4. No spaces or special characters allowed (@, #, $ etc.)
  5. Cannot be a keyword (e.g., int, float are INVALID as identifiers)
  6. C is case sensitive: sum ≠ Sum ≠ SUM

✅ Valid: sum, _count, total1, myVar   ❌ Invalid: 1sum, total@, my name, int


Keywords: Reserved words with fixed predefined meaning. Cannot be used as identifiers. C has 32 keywords.

Examples: int, float, char, double, void, if, else, switch, case, for, while, do, return, break, continue, goto, struct, union, typedef, auto, static, extern, register

Q3: What is recursion? Advantages and disadvantages? 4 marks

A function that calls itself is called a recursive function. It must have a base condition to stop infinite recursion.

Advantages: Code becomes shorter and cleaner | Useful for tree/graph problems | Solves complex problems easily

Disadvantages: Uses more memory (stack) | Slower than loops | Risk of stack overflow if base case missing

#include <stdio.h>

int fact(int n) {
    if(n == 0 || n == 1) return 1;  // Base case

3. Swap using Call by Value vs Call by Reference:

// Swap - Call by Value (changes NOT reflected) 
#include <stdio.h>

void swapValue(int a, int b) {  // Copy is passed
    int temp = a; a = b; b = temp;
}

void swapRef(int *a, int *b) {  // Address is passed
    int temp = *a; *a = *b; *b = temp;
}

int main() {
    int x = 5, y = 10;
    swapValue(x, y);
    printf("After Call by Value: x=%d y=%d\n", x, y);  // x=5 y=10 (unchanged!)

    swapRef(&x, &y);
    printf("After Call by Reference: x=%d y=%d\n", x, y); // x=10 y=5 (changed!)
    return 0;
}

Q2: What is a union? How is it different from structure? 4–12 marks

A union is a user-defined data type where all members share the same memory location.

  • Size of union = size of its largest member
  • Only ONE member holds a valid value at a time
  • Last written value is stored (previous values overwritten)
  • Used to save memory

Q1: What is a pointer? Declaration, initialization, dereferencing. 4–12 marks

A pointer is a variable that stores the memory address of another variable.

Declaration: data_type *pointer_name;

Example: int *ptr; — ptr is a pointer to an integer

Initialization: ptr = &variable;

Example: int a = 10; int *ptr = &a; — ptr holds address of a

Operators:

  • & (Address-of operator): Gets address of variable. &a = address of a (e.g., 1000)
  • * (Dereferencing operator): Gets value at address. *ptr = value at address stored in ptr = 10
// Pointer example 
int a = 10;
int *ptr = &a;
printf("%d", a);     // 10   (value of a)
printf("%p", &a);   // 1000 (address of a)
printf("%p", ptr);   // 1000 (address stored in ptr)
printf("%d", *ptr);  // 10   (value at address 1000)

Uses/Advantages of Pointers:

  1. Dynamic memory allocation (malloc, calloc)
  2. Call by reference — modify original values
  3. Array traversal — efficient and fast
  4. Linked lists, trees, graphs — self-referential structures
  5. Reduces code length and complexity
  6. Used with structures via -> operator

    fp = fopen("student.dat", "rb");

1What are identifiers? Rules?U120142017

while=entry-controlled(condition before); do-while=exit-controlled(condition after, runs at least once). do-while ends with semicolon after while(cond);

Block of code for specific task. Types: Library (printf, scanf) and User-defined. Prototype = declaration before use → tells compiler return type + params. Syntax: return_type func_name(params);
6Call by Value vs Call by Reference with swap program?U22015201620212025
Value=copy passed, original unchanged, no pointer. Reference=address passed using & and *, original changes. Swap by ref: void swap(int *x, int *y){int t=*x;*x=*y;*y=t;} called as swap(&a,&b);
7What is recursion? Write factorial program.U2201420152016
Function that calls itself. Must have base case. fact(n){if(n==0||n==1)return 1; return n*fact(n-1);} Adv: clean code. Disadv: uses more memory, risk of stack overflow.
8Write Fibonacci using recursion.U220152016
fib(n){if(n<=1)return n; return fib(n-1)+fib(n-2);} Output for 7 terms: 0 1 1 2 3 5 8
9Storage classes — auto, register, static, extern?U22015201620172025
auto=default,garbage,block | register=CPU,fast,block | static=retains value,0 default,entire program lifetime | extern=global,0 default,across files
10Local vs global variables?U2201720192021
Local=declared inside function, accessible only inside that function, default=garbage. Global=declared outside all functions, accessible everywhere, default=0.
11What is an array? 1D and 2D?U32014201520162019
Collection of similar elements in contiguous memory, accessed by index (starts 0). 1D: int a[5]={10,20,30,40,50}; 2D: int m[3][4]; accessed as m[i][j]
122D array initialization and access?U320152016
int a[2][3]={{1,2,3},{4,5,6}}; Access: a[i][j] where i=row, j=col. Memory is Row-major. 2D memory formula: Base + (i*cols + j)*size
13What are strings? String functions?U320142021
char array ending with '\0'. char str[20]; scanf("%s",str); Functions in string.h: strlen, strcpy, strcat, strcmp. strcmp returns 0 if equal.
14What is a structure? Write syntax and program.U4Every Year
User-defined type grouping different data. struct Student{int roll; char name[20]; float marks;}; Access with dot: s.roll. With pointer: ps->roll. Size = sum of all members.
15What is a union? Difference from structure?U42015201620172025
Union = all members share same memory. Size=largest member. Only one active at a time. Structure=separate memory for each, size=sum. Struct=many values; Union=one at a time, saves memory.
16What is self-referential structure?U420172019
Structure containing pointer to same type. Used for linked lists, trees. struct Node{int data; struct Node *next;}; Allows chaining of nodes.
17Bitwise operators in C?U42017
&=AND(both1→1) | |=OR(any1→1) | ^=XOR(diff→1) | ~=NOT(invert) | <<=left shift(×2) | >>=right shift(÷2). Example: 5&3=1, 5|3=7, 5^3=6, 5<<1=10
18What is a pointer? Declaration and uses?U5Every Year
Variable storing address of another variable. int *p=&a; &=address-of, *=dereference. Uses: dynamic memory, call by reference, arrays, linked lists, functions, structures.
19Pointer arithmetic?U520172022
p+1 moves by sizeof(data_type). For int (4B), p+1 adds 4 to address. p+n=move n elements ahead. Cannot add two pointers. Can subtract: p2-p1 = elements between.
20Access array using pointer?U520152016
int arr[5]={10,20,30,40,50}; int *p=arr; *(p+i) or p[i] accesses arr[i]. arr[i] is same as *(arr+i). Array name = constant pointer to first element.
21Arrays of pointers?U52022
Array where each element is a pointer. char *names[3]; names[0]="Ram"; names[1]="Shyam"; Each stores address of string. Efficient for multiple strings (no wasted space).
22Pointer with structure — -> operator?U5201620182022
struct Student *ps=&s; ps->roll same as (*ps).roll. Use -> when pointer to struct, use . when direct struct variable. MCQ: -> operator for struct pointer (2018 PYQ).
23NULL, wild, and dangling pointers?U52021
NULL=initialized to nothing (safe), int *p=NULL; Wild=uninitialized (dangerous). Dangling=freed memory (undefined). Always initialize pointers! char*p=0; *p='a'; = RUNTIME ERROR (2025).
24What is preprocessor? What does it do?U620162025
Processes source code before compilation. Commands start with #. Tasks: remove comments, expand macros, insert header files, handle conditional compilation. Runs before compiler.
25#define for constants and macros?U6201520172025
Constants: #define PI 3.14; Macros: #define SQ(x) ((x)*(x)); No semicolon. Always use parentheses around args. No memory used — inline expansion. Faster than functions.
26Macro vs Function differences?U62015201620172025
Macro: preprocessor, inline, fast, no type check, no memory. Function: compiler, call overhead, slower, type checked, uses stack. Use macro for simple tasks, function for complex.
27What is a file? Why needed? fopen() modes?U72015201620192025
File=data on disk, permanent. Needed for permanent storage. fopen(name,mode): r=read, w=write(new), a=append, r+=read+write, w+=read+write(new), rb/wb=binary. Returns NULL on failure.
28File I/O functions — read and write?U7201520192025
Write: fprintf(fp,"fmt",var), fputc(ch,fp), fputs(str,fp). Read: fscanf(fp,"fmt",&var), fgetc(fp), fgets(str,n,fp). Binary: fwrite(&var,size,n,fp), fread(&var,size,n,fp).
29fseek(), ftell(), rewind() with example?U720222025
fseek(fp,offset,SEEK_SET/CUR/END)=move pointer. ftell(fp)=current position in bytes. rewind(fp)=go to beginning (=fseek with SEEK_SET,0). Used for random access files.
30Sequential vs Random access files?U720222025
Sequential=read in order from start, uses fgetc/fgets. Random=jump to any position with fseek(), fast direct access, uses fread/fwrite. Binary files support random access better.
